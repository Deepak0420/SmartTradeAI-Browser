SmartTradeAI Browser 🚀

Project Vision

Build an advanced Android browser with an integrated AI trading assistant and a premium futuristic interface.

Core Features

1. Advanced Browser

- Modern address bar
- Multiple tabs
- Back, forward and refresh
- Bookmarks and browsing history
- Downloads manager
- Desktop mode
- Website login and session support
- Support Binance, Binomo, Google and other websites

2. AI Trading Assistant

- AI chat interface
- Chart screenshot analysis
- Candlestick pattern recognition
- RSI, MACD and EMA analysis
- Trend direction and support/resistance analysis
- Risk management guidance
- Voice input and spoken responses

3. Floating AI Assistant

- Movable floating overlay
- Works over other apps with Android permission
- Expandable AI panel
- User-authorized screen capture
- Live analysis only when a genuine data source is available

4. Premium UI

- Futuristic dark interface
- Advanced dashboard
- Smooth animations
- Modern cards and charts
- Professional navigation
- Responsive Android design

Trading Safety

- Analysis only. No automatic trading.
- Never click Buy or Sell automatically.
- Binance connection must be read-only.
- Never request withdrawal or transfer permissions.
- Clearly distinguish Binomo Crypto IDX/OTC from Binance market prices.

Technology Direction

- Android native application
- Kotlin
- Jetpack Compose
- Android WebView
- Secure local storage
- GitHub Actions for APK builds

Project Rules

- Android only for the initial release.
- Laptop Chrome Extension is postponed.
- Never commit API keys or passwords.
- Ask permission before screen capture.
- Do not publish APK until implementation and build checks pass.
